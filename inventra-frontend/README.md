# Inventra Frontend

Professional responsive React/Vite frontend for the Inventra Spring Boot backend.

## Run

```bash
npm install
npm run dev
```

The frontend expects the backend at `http://localhost:8081/api`. Override with `VITE_API_URL` in `.env`.

## Included

- JWT login/register/logout
- Dashboard
- Product management
- Warehouse network and per-warehouse inventory
- Inventory transactions
- Orders and fulfillment/cancellation
- Returns
- Purchase orders and receiving
- Alerts
- AI forecasting and smart replenishment
- Anomaly detection
- Product recommendations
- Inventory assistant
- Responsive desktop/tablet/mobile layout
